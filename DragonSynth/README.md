## 🚀 Quick Install (Windows)

### Prerequisites
1. **Visual Studio 2022** (free): https://visualstudio.microsoft.com/
   - Select **"Desktop development with C++"** during install
2. **CMake**: https://cmake.org/download/
   - Check **"Add CMake to PATH"** during install

### Install
1. Extract the zip file
2. **Right-click** `BUILD_AND_INSTALL.bat` → **Run as administrator**
3. Wait 5-10 minutes for build
4. Done! Open your DAW and scan for plugins

## 🎹 Features

| Feature | Description |
|---------|-------------|
| **Dual Oscillators** | Sine, Saw, Square, Triangle, Noise |
| **Filter** | Low Pass, High Pass, Band Pass with resonance |
| **Envelopes** | Amp ADSR + Filter ADSR |
| **16 Voices** | Full polyphony |
| **PC Keyboard** | Play with your computer keyboard |

| S D G H J | C# D# F# G# A# |
| Q W E R T Y U | C D E F G A B (octave up) |
| 2 3 5 6 7 | C# D# F# G# A# (octave up) |

**Controls:**
- `[` / `]` - Octave down/up

## 🎵 Using in Your DAW

### FL Studio
Options → Manage Plugins → Start scan → Find "Dragon Synth"

### Ableton Live  
Preferences → Plug-ins → Rescan → Find "Dragon Synth"

### Other DAWs
Rescan VST3 plugins, look for "Dragon Synth"

## 📁 Install Locations

- **VST3**: `C:\Program Files\Common Files\VST3\Dragon Synth.vst3`
- **Standalone**: `%USERPROFILE%\Dragon Synth\Dragon Synth.exe`
